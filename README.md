# איזה כלב מתאים לי

אתר בעברית שמתאים זן כלב לחיים של המשתמש, ומציג לכל זן גם את הטוב וגם את הרע. גרסה 1, בלי שרת: כל הנתונים בקבצי JSON, והתשובות נשמרות רק במכשיר.

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות לנוסחת ההתאמה (Vitest)
npm run e2e        # בדיקות נגישות (axe) ומקלדת לכל המסכים (Playwright)
npm run build      # גרסת הפצה בתיקייה dist
```

## מה יש באתר

| נתיב | מסך |
| --- | --- |
| `/` | מסך פתיחה (הכלב רץ פנימה ונכנס לעיגול בפינה) ודף נחיתה עם שני מסלולים |
| `/quiz`, `/quiz/refine` | השאלון בתור טיול: 18 שאלות, ואחרי התוצאה עוד 8 שאלות לדיוק |
| `/results` | חשיפת התוצאות, עם "כדאי שתדע" לכל כלב |
| `/library` | ספריית הכלבים, קרוסלה בהירה |
| `/breed/:id` | עמוד הזן: במה כהה בצבעי הזן, סיור בגוף ב־5 עצירות, "הטוב והרע" |
| `/compare` | השוואה בין שני זנים |
| `/soon` | "כבר יש לי כלב", בקרוב |
| `/emergency` | מסך חירום עם כפתורי חיוג |
| `/accessibility` | הצהרת נגישות |

## איך מוסיפים זן

1. מוסיפים רשומה ל־`src/data/breeds.json`: מזהה, שם, 12 ציונים (1 עד 5), מקור לכל ציון (`chayuta` או `estimate`) ונתוני `care`. לא צריך לשנות קוד.
2. שמים ב־`public/dogs/` שלושה קבצים בשם המזהה, עם קו תחתון במקום מקף: `<id>.webp` (תמונה), `<id>_run.webp` (ריצה) ו־`<id>.glb` (מודל).
3. אם רוצים צבעי במה משלו, מוסיפים שורה ב־`src/lib/breedTheme.ts`. בלי זה הזן מקבל את ברירת המחדל.

החלפת המודלים במודלים טובים יותר נעשית במקום אחד: `src/lib/dogAssets.ts`. שם נמצאים גם זוויות המצלמה והנקודות על הגוף.

## הנוסחה

`src/lib/scoring.ts` הוא תרגום אחד לאחד של הנוסחה מהמפרט: לכל תכונה `max(0, 1 − d/2)`, משקל 3 לעדיפויות ומשקל 1 לשאר. המיפוי משאלה לערך נמצא ב־`src/lib/quiz.ts`. הבדיקות משחזרות את הדוגמה המחושבת (שי צו 88%).

## הגדרות לפני השקה

משתני סביבה (קובץ `.env`):

- `VITE_SIGNUP_ENDPOINT`: כתובת שמקבלת את ההרשמה לעדכונים. בלי זה הטופס לא מוצג.
- `VITE_A11Y_NAME`, `VITE_A11Y_EMAIL`, `VITE_A11Y_PHONE`: פרטי רכז הנגישות להצהרה.

שם האתר נמצא ב־`src/config.ts`.

## פתוח

- ציונים שמסומנים `estimate` צריכים בדיקה של וטרינר או מאלף.
- רשימת מוקדי החירום ממקור משנת 2020 ולא אומתה.
- כלבי התלת ממד הם אב טיפוס.
- הטקסט המלא של כל זן ו"שאלות למגדל" עוד לא הועברו מהמסמך לאתר. "הטוב והרע" נגזר בינתיים מהציונים.
